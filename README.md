## Getting Started

This project uses [docsygen](https://github.com/YOUR_USER/docsygen) commands to bootstrap documentation and structure.

Run `/guide` in Claude Code to see the full workflow. The short version:

1. Write raw notes in `.docs/idea.md`
2. `/seed` to generate a structured seed document
3. `/prototype` to define UX flows
4. `/stack` to define the tech stack
5. `/design` to create the design system
6. `/resume` to pick up where you left off
