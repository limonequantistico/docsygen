## Getting Started

This project uses [docsygen](https://github.com/YOUR_USER/docsygen) commands to bootstrap documentation and structure.

Run `/help` in Claude Code to see the full workflow. The short version:

1. **Think**
   - Capture notes in `.docs/idea.md`
   - `/seed` for a structured seed; use `/seed-update` and `/seed-review` as you iterate

2. **Shape**
   - `/prototype` — prompt for external design tools
   - `/prototype-verify` — review wireframes
   - `/stack` then `/design`

3. **Build**
   - `/scaffold` → `/setup`
   - `/component` and `/next` (work through the backlog)
   - `/resume` — fresh situational check-in

4. **Maintain**
   - `/tidy` — clean the backlog
   - `/sync` — reconcile docs with the codebase

**Tip:** Drop tasks in `.docs/backlog.md` anytime; `/next` runs the next backlog item.
